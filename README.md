# TCS Website Clone (HTML + CSS)

A simple clone of the Tata Consultancy Services (TCS) website built using only basic HTML and CSS.

## 🚀 Overview
This project focuses on recreating the clean and structured UI of the TCS website while using only fundamental CSS concepts like margin, padding, and positioning.

## ✨ Features
- Clean corporate-style UI
- Structured layout inspired by TCS
- Built without Flexbox or Grid
- Focus on spacing and alignment

## 🛠 Tech Stack
- HTML5
- CSS3

## 🧠 What I Learned
- Strong understanding of the CSS box model
- Layout structuring using basic CSS
- Importance of spacing in professional UI design
- Building responsive-like layouts without modern tools
